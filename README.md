# Theo Slater — Portfolio

Personal portfolio for Theo Slater, a UK software engineer building open-source apps and tools.

Live site: [theoslater.is-a.dev](https://theoslater.is-a.dev/)

## Development

```sh
pnpm install
pnpm dev
```

## Production build

```sh
pnpm build
pnpm preview
```

Built with React, TypeScript, and Vite.
